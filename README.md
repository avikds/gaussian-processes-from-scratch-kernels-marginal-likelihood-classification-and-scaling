# gaussian-processes-from-scratch-kernels-marginal-likelihood-classification-and-scaling
Build Gaussian processes the way chapter 17 of Murphy's Probabilistic Machine Learning teaches them, in numpy with nothing but a Cholesky factorization and an optimizer. Write a kernel library (squared exponential with ARD length scales, Matern, periodic, linear, sums and products), check Mercer's condition on Gram matrices and draw functions…
